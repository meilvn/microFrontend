rule 如何判定隔离结果
检查项 默认模式（样式注入 document） strictStyleIsolation（shadow DOM）
body 背景 / h1 / a / ::selection 可能污染宿主页面 → 观察主应用是否"变样" 收进 shadow root → 对宿主无影响
Material 弹窗（CDK overlay） 正常（主题样式全局生效） 弹窗在 shadow root 外 → 样式丢失 / 裸奔
外部字体（@import url() 构建期内联为 @font-face） 字体文件（fonts.gstatic.com）运行时正常加载 需验证 shadow root 内字体规则与跨域字体加载行为
规避方案 「弹窗演示」页可将 overlay 挂到 app-root 内部（含 shadow 穿透），让弹窗继承作用域样式
